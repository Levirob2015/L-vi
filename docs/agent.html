Von Webseiten lernen

Mit dem Knopf Lernen in deiner Favoritenleiste liest dein Agent die Seite, die du gerade offen hast, und kann danach Fragen dazu beantworten. Er nennt dabei immer die Quelle.

Lernen-Knopf in Safari einrichten (einmalig, ca. 1 Minute)
  1. Tippe auf Code kopieren.
    Lernen
  2. Öffne in Safari irgendeine Webseite, tippe auf Teilen → Lesezeichen hinzufügen. Name: Lernen, Ort: Favoriten. Sichern.
  3. Tippe auf das Buch-Symbol (Lesezeichen) → Favoriten → Bearbeiten → tippe auf Lernen.
  4. Lösche die Adresse, füge den kopierten Code ein und tippe auf Fertig.
  5. Blende die Favoritenleiste ein: Aa bzw. Einstellungen → Safari → Favoritenleiste anzeigen. Jetzt steht Lernen über jeder Webseite.

Der Knopf öffnet den Agenten unter und kopiert die Seite zusätzlich in die Zwischenablage. Nutzt du den Agenten als Home-Bildschirm-App, hat diese ein eigenes Gedächtnis: dort nach dem Tippen auf Lernen einfach unten den Text einfügen.

Eigene Notizen

Fakten, die dein Agent kennt. Er durchsucht sie, wenn keine Fähigkeit passt. Im Chat geht's auch: „Merke dir, dass …“.

Agent

Darunter fragt der Agent nach, statt zu raten.

Sichern und übertragen

Alles liegt nur in diesem Browser. Kopiere die Sicherung in eine Notiz oder Datei, um sie aufzuheben oder auf ein anderes Gerät zu bringen.

Auf dem iPad als App

In Safari öffnen, auf Teilen tippen, dann Zum Home-Bildschirm. Der Agent bekommt ein eigenes Symbol und startet ohne Browserleiste. Er braucht kein Internet und schickt nichts weg: Training und Antworten laufen auf dem iPad. Statt der Mikrofon-Taste geht immer auch das Diktier-Mikrofon der iPad-Tastatur.

Neu anfangen

Setzt Fähigkeiten, Gedächtnis und Chat auf die Beispiele zurück.
